日期：2026-10-02。环境：Windows 10.0.26200，node v22.23.2，Microsoft Edge 154.0.4258.48（headless）。

两项收口：M3.2 给 ideas / sandbox / steal-this / open-questions 四页补最小检查脚本并逐个复跑；M3.3 给 `50-design/08-深色主题样张.html` 备齐浏览器客观证据（1440 / 375 两档全页截图、::selection 像素与对比度实算）。深色样张的最终目检确认留给用户，本文只提供客观证据。

## M3.2 四页检查脚本复跑

八张视觉稿中 why / glossary / limits / field-notes 自带检查脚本，ideas、sandbox、steal-this、open-questions 四张没有。按主流程拍板的「补脚本复跑」方案，为四页各写一个 `check.mjs`，放在各页同目录：

- `50-design/视觉稿/ideas/check.mjs`
- `50-design/视觉稿/sandbox/check.mjs`
- `50-design/视觉稿/steal-this/check.mjs`
- `50-design/视觉稿/open-questions/check.mjs`

脚本各 114 行，node 直跑、无依赖，检查两件事：

1. 规则 1 · 单一色相（声明值口径）：全文提取 hex 与 oklch 声明，换算 OKLCH，C≥0.02 的色相必须全部落在钴蓝 265±5°，出现任一第二色相即 FAIL；C<0.02 近中性豁免（与 04-定稿规则 1、limits/check-limits.mjs 同口径）。
2. 规则 2 · 文字对比度（8-bit 合成口径）：除纸白外的每个前景声明，带 alpha 先对纸白 #FAFAF7 做 sRGB 8-bit 合成取整，再按 WCAG 2.x 相对亮度实算。阈值沿用 brand-spec 红线：α≥0.78 或 1 按文字档 ≥4.5 判，0.50≤α<0.78 按图解线档 ≥3 判，α<0.5 装饰档照录不设线。

复跑命令：`cd 50-design/视觉稿/<页> && node check.mjs`

## M3.3 深色样张截图与客观检查

对象：`50-design/08-深色主题样张.html`，md5 `cfce1d1f7928f8c0d937c0229fca7c95`。该样张审记「未做」一节记录了浏览器渲染目检缺项，本节补上客观证据。

### 方法

Edge 154.0.4258.48 headless（`--headless=new`）加 DevTools 协议驱动（node 22 全局 WebSocket，无第三方依赖）。有个方法上的坑照录：直接 `--window-size=375` 会被 Edge 钳到最小窗宽，实际回读视口 492×708，不是 375。改用 CDP `Emulation.setDeviceMetricsOverride` 精确设视口：1440×844（mobile=false）、375×844（mobile=true），deviceScaleFactor=1，`Page.captureScreenshot` 开 `captureBeyondViewport` 取全页。

截图取自与原文件逐字节同 md5 的临时副本，未改动项目文件；探针脚本注入两件事：回读计算样式（含 `getComputedStyle(el, '::selection')`），以及用 Range 程序化选中 `.sub` 正文整段（无鼠标交互下让 ::selection 实际上屏）。Google Fonts 经网络加载成功（`document.fonts.check` 对 Noto Serif SC / Noto Sans SC 均 true，`fonts.status=loaded`）。

### 客观检查记录

布局回读：scrollWidth 与视口宽相等（1440 档为 1440，375 档为 375），无横向滚动；375 档 <960 断点生效，竖排单列（截图可见报头折行、场景移至正文下方）。

::selection 计算样式回读（两档一致）：`background = oklch(0.776 0.086 269.6 / 0.14)`（即 --ink-14）；`color` 未被 ::selection 覆写，随元素色（.sub 为 82% 档）。页面 body/h1 计算色分别为 oklch(0.196 0.017 268.8) 与 oklch(0.776 0.086 269.6)，与令牌一致。

像素证据（自写 PNG 解码：zlib 解压 + 逐行去滤波；色值按精确匹配计数）：

- 暗纸：全图 1/4 采样主色 top1 为 #12151D（plain-1440 占 295,958 个采样点，plain-375 占 76,912），暗纸渲染正确。
- 选区已实际上屏：选区矩形（1440 档 x71,y451,404×56；375 档 x39,y351,292×56）内精确 #262B3A（墨 14% 合成值）像素 10,884 个，占矩形 48.1% / 66.6%；未选中对照图同矩形为 0。全图对比 plain 图与选区图：#12151D 减少 3,301 个采样点，#262B3A 增加 3,301 个，两档一致（同段文字同字号，换行位置不同但总墨迹相同）。
- 选区内文字色：首词「Cordis」是 `.term`（全墨 #A0B4EE，扫描线像素验证），其余正文按 82% 档渲染。

::selection 相关对比度实算（8-bit 合成口径，本次自算，非引用审记数）：

| 配对 | 实算 | 参照线 | 判定 |
|---|---|---|---|
| 墨 1.0 #A0B4EE 对暗纸 #12151D | 8.91:1 | ≥4.5 | 过 |
| 选区底 #262B3A 对暗纸 #12151D | 1.29:1 | WCAG 1.4.11 非文字 3:1 | 未达，照录 |
| 选区内正文（82% 档合成 #8A9BCE）对选区底 | 5.14:1 | ≥4.5 | 过 |
| 选区内全墨字（.term #A0B4EE）对选区底 | 6.89:1 | ≥4.5 | 过 |

一处口径修正入档：08 文件头注释与审记写「选区上的墨字实测 6.89:1」，那是全墨字对选区底的数；实际被选中的 `.sub` 正文是 82% 档，实算 5.14:1，仍过 ≥4.5 红线，审记「选区里认字没问题」的结论不变。

### 留给用户的目检确认

暗纸观感与选区是否「可辨」由用户看上面四张截图做最终判断。客观侧事实两条：选区底对暗纸 1.29:1，低于非文字 3:1 参照线，属于含蓄的一档；像素级证实选区色块确实成片画上（矩形内近半 / 三之二面积为 #262B3A），选区上认字 5.14 / 6.89 过线。本项执行中已预读 1440 与 375 两档选区截图：字体、暗纸底、SVG 描边、选区色块渲染均无事故。
