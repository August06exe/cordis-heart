### 1.2 候选实算与淘汰

候选 A · 抬 alpha 保文字不动：把选区底从 .14 抬到能过 3:1 的 alpha，文字仍按元素色渲染。

定案 · 全反白：底 = 墨本体 `var(--fg)`，字 = 纸色 `var(--paper)`。

## 5. Astro 主题切换组件 · CSS 变量命名约定

### 5.1 两条词表的关系

库内现有两套名字：样张在用的密度令牌（`--bg`/`--fg`/`--ink`/`--ink-XX`/`--paper`）和 brand-spec 的语义名（`--surface`/`--muted`/`--border`/`--accent`）。约定以样张词表为唯一真值层，brand-spec 名字全部保留为语义别名，指向真值层。组件样式只许引用语义别名与 `--fg`/`--ink` 本体，不许出现 alpha 字面量和新 hex。

### 5.2 命名规则

1. 两主题同名同构：变量名在浅深两套里完全一致，切换只换值、不改名。任何令牌必须两主题同时给值、同时过线，缺一边就不许合入。
2. 密度层命名 `--ink-<alpha×100>`：现行步进 .14 / .20 / .70 / .78 / .80 / .82（04-定稿规则 1 的全站唯一阶梯）。新增密度档要先过 node 对比度实算，并两主题同给。
3. 语义别名一律 `var()` 指向，不得自带色值。
4. 单墨纪律：不引入第二色相的变量名。`--accent` 恒等于 `var(--fg)`，这是 brand-spec 的单墨规则，不是可选项。
5. 状态对（::selection、:focus-visible 这类）写成 var 组合，主题无关，本次修复的 `::selection{ background: var(--fg); color: var(--paper); }` 原样带走，任何主题下自动双过线。

### 5.3 作用域与切换机制

```html

<script is:inline>
  const t = localStorage.getItem('theme') ??
    (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
  document.documentElement.dataset.theme = t;
</script>
```

```css
:focus-visible{ outline: 2px solid var(--focus-ring); outline-offset: 3px; }
```

切换组件只做两件事：写 `localStorage.setItem('theme', …)` 与同步 `document.documentElement.dataset.theme`。auto 档由头部脚本在每次进站时解析，不进 CSS 媒体查询，避免深色值写两份。

### 5.4 合入校验纪律

改令牌、加令牌的提交必须附 node 实算数：口径 8-bit 合成取整（08-审记复现节公式），红线文字 ≥4.5、图解线 ≥3、::selection 双线 3 + 4.5、装饰档照录。两主题同名令牌成对出现，对账清单（第 4 节）同步更新。
