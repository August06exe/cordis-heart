# 生态调研

v1.0 · 2026-10-02 · 配套文档：01-PRD.md、02-技术方案.md、04-测活报告.md

## 导语

本次调研围绕本站技术栈（Astro + 原生 TS + GSAP 3 ScrollTrigger + 内联 SVG，钴蓝单墨编辑风、滚动叙事）分两路进行：一路查 GitHub Agent Skill 生态（anthropics/skills 官方仓、ComposioHQ 与 travisvn 两大 awesome 索引、10 个垂类仓库），另一路查网站与开源项目（GSAP 官方生态、数据新闻与 Scrollytelling 开源实现、原生 TS/SVG 动效库、教育型文档站交互模式），共 23 项发现。结论有三条：动效骨架的正解在 GSAP 官方文档四条（全插件免费、matchMedia 降级、Timeline 定拍、ScrollTrigger scrub/pin/progress），生态里没有一个大而全的 GSAP 权威技能，最接近的 iart-ai/web-animation-skills 与 genjutsu 都要挑子集用；开源富矿在 The Pudding、Observable 一侧，大报当代 scrollytelling 代码基本不开源；任何内置品味清单引入前必须本地化改写，auteur 的禁令会误伤本站的纸白底。fit 分级含义：direct 原样可用，adapt 取子集并做本地化改造，idea-only 只做参照不引入。两路调研的测活记录未返回，下列技能均未在本项目实际安装运行，运行效果待 M2/M4 验证。

## 一、动效与叙事

### GSAP 3.13+ 全插件免费（direct）

链接：https://gsap.com/blog/3-13

它是：GSAP 官方公告。因 Webflow 收购，全部原 Club 付费插件免费商用，已并入公共 npm 包（2025-04-29）。

可抄：`npm i gsap` 后直接 `import { DrawSVGPlugin } from "gsap/DrawSVGPlugin"`，本站最需要的 SVG 描线不再手写 stroke-dashoffset；SplitText 新版自带 aria-label/aria-hidden 与 autoSplit 响应式重切，标题分行入场即装即用。实测 `npm view gsap version` = 3.15.0；unpkg 文件清单含 DrawSVGPlugin、SplitText、MorphSVG、ScrollSmoother、InertiaPlugin、Flip 全部插件文件。

理由：对既有 GSAP 3 栈零迁移成本、免费商用，公告原文与包内容均已实测核实。

### gsap.matchMedia()（direct）

链接：https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/

它是：GSAP 3.11+ 的响应式动画 API，按媒体查询条件包住初始化代码，条件失效时自动 revert 全部动画与 ScrollTrigger。

可抄：条件对象写法 `mm.add({ reduceMotion: "(prefers-reduced-motion: reduce)" }, (ctx) => { ... duration: ctx.conditions.reduceMotion ? 0 : 正常值 ... })`。reduce 分支用 duration:0 直达终态，保信息完整；条件翻转时 tween、ScrollTrigger、pin 全部自动清理，无需手写卸载逻辑。

理由：官方 API，是本项目 reduced-motion 降级的标准答案。要点是降级等于 duration:0 直达终态，删掉动画反而是错误做法。

### GSAP Timeline（direct）

链接：https://gsap.com/docs/v3/GSAP/Timeline/

它是：GSAP 主时间轴文档，标签系统与位置参数。

可抄：每页叙事建一条主 tl，`addLabel("beat-1")` 到 `"beat-5"` 五拍定锚；插入动画用位置参数 `"beat-2+=0.4"` 微调节拍，改时长自动重排全轴；重播按钮绑 `tl.restart()`。

理由：苹果式可重播时间轴的官方组织方式，不需要手算任何秒数。

### ScrollTrigger（direct）

链接：https://gsap.com/docs/v3/Plugins/ScrollTrigger/

它是：ScrollTrigger 官方文档。

可抄：章节 pin+scrub，`scrub: 1` 让进度落后滚动条 1 秒追赶，获得顺滑 scrub；顶部阅读进度条用 `onUpdate: (self) => self.progress`（0 到 1 只读）驱动一根 scaleX 墨线；字体或内容晚加载改变布局后调 `ScrollTrigger.refresh()` 重算 start/end；文档明示被 pin 的元素本身不要做动画（影响测量）。

理由：scrub、pin、progress 就是本站滚动叙事的全部骨架，均已核实存在于文档。

### flubber（adapt）

链接：https://github.com/veltman/flubber

它是：SVG 形状补间库，任意两个闭合 path 之间平滑插值（6.9k stars，MIT，npm 实测 0.4.2）。

可抄：`flubber.interpolate(pathA, pathB)` 生成 d 值插值器，接进 GSAP tween 的 onUpdate 逐帧 `setAttribute('d', ...)`，做概念 A 图形到概念 B 图形的墨线形变；一对多用 separate/combine，批量用 interpolateAll。README 未提 TS 类型，需自补一个 d.ts。

理由：MIT、零依赖、纯 vanilla；注意多形状 path 只取首个外轮廓，选形时要避开。

### Lenis（adapt）

链接：https://github.com/darkroomengineering/lenis

它是：轻量平滑滚动库（16.1k stars，MIT，npm 实测 1.3.26），README 内置与 ScrollTrigger 的官方接线。

可抄：官方三行接线 `lenis.on('scroll', ScrollTrigger.update)` + `gsap.ticker.add((t) => lenis.raf(t * 1000))` + `gsap.ticker.lagSmoothing(0)`；respectReducedMotion 默认 true，自动关平滑、瞬跳定位。官方 ScrollSmoother 已随 gsap 包免费（实测在包内），与 Lenis 二选一。

理由：增强项非必需；引入后 pin、锚点跳转、resize 必须真机回归，是否引入等 M4 回归测试定夺。

### Scrollama（adapt）

链接：https://github.com/russellsamora/scrollama

它是：数据新闻界事实标准的 scrollytelling 库（零依赖，6k stars，MIT，npm 实测 3.2.0）。

可抄：IntersectionObserver 的 stepEnter/stepExit（offset 0.5 阈值 + progress 模式回报步内 0 到 1 进度）做文字步骤到图形状态的切换，免 pin、移动端不抖；其 offset 阈值与 once/enable/disable 生命周期设计可照搬。

理由：与 ScrollTrigger 职责重叠，不引入库，读它的 step 语义照抄思路，全站只留一套滚动监听。

### awesome-html-scrolline-deck（adapt）

链接：https://github.com/gongnyang/awesome-html-scrolline-deck

它是：滚动叙事 HTML 演示的 Claude Code 技能：scene-ledger 场景台账 + Node CLI + 强制浏览器彩排门禁。

可抄：两条纪律加进 M2 演示评审清单：场景开工前先在台账登记主张、依据、滚动变化、pass-hold-scrub 节奏，无台账不开工；跳过浏览器验证不许报完工，且三视口（1440×900、1920×1080、约 390px）实拍复核。

理由：形态是演示 deck，借台账与彩排纪律、不搬引擎；三视口复核正对「手机宽度不破版」验收项，其 reduced-motion 同信息静态呈现与本站红线一致。

## 生态坑位（调研中踩到的共性风险）

1. 安装粒度：多数仓库是 skills/ 目录下的技能集合，全量安装会把 glassmorphism、threejs、SwiftUI 等无关能力一并带入，稀释 agent 注意力；只拷需要的子目录。
2. 品味表冲突：auteur 等技能内置的反 AI 味禁令与本站定调有条目级冲突（auteur 禁奶油色与暖白背景，而纸白 #FAFAF7 是本站地基）；引入任何品味清单前必须本地化改写，否则 lint 会拦掉刻意的设计。
3. 框架假设：静态分析类技能（jsx-a11y 模式、各家 React 检测）默认 React/Next；本站是无框架 TS，只取浏览器运行时部分（live DOM 上的 axe-core、Playwright）。
4. 星数不等于质量：brumley 仅 2★ 但管线最贴本站性能预算；76k★ 的大索引反而找不到一个 GSAP 技能。
