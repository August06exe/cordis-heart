2026-10-03。任务：对 `50-design/视觉稿/` 八页视觉稿与 `50-design/03-首页小样-OD/cordis-hero.html` 逐页跑浏览器四档响应式实测（1440 / 1024 / 768 / 375），断言无横向滚动，并把 DesignRead 定稿（`50-design/04-DesignRead-定稿.md`）评审标准规则 4（内容覆盖）与规则 6（工程红线）逐页人工过一遍。方法沿用 M1 测活（`99-archive/2026-10-02-测活/gsap-probe-审记.md` 第六节）验证过的 Edge headless + CDP 工具链。

## 一、结论

规则 5 全过：9 页 × 5 档（任务四档加定稿原口径的 1280）共 45 次视口检查，`scrollWidth` 与 `clientWidth` 全部相等，零页面级横向滚动。控制台 0 报错 0 异常。prefers-reduced-motion 降级后内容零缺失。滚动到底再倒滚全程无报错。hero 小样「960px 以下塌单栏不破版」的历史结论实测补证成立。

## 二、方法与复现命令

环境：Windows 10.0.26200，Edge 154.0.4258.48（`--headless=new`），Node v22.23.2（内置 WebSocket 跑 CDP，无第三方依赖）。Google Fonts 与 cdnjs 实测可达（curl 均 200），截图为 webfont 渲染。

```cmd
:: 1. 起 headless Edge（CDP 端口 9333）
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new ^
  --remote-debugging-port=9333 --user-data-dir=%TEMP%\resp-probe\profile ^
  --no-first-run --disable-gpu --window-size=1440,900 about:blank

:: 2. 逐页跑五档视口 + reduce + 滚动往返（约 5 分钟）
node %TEMP%\resp-probe\resp-probe.mjs          :: 脚本副本在归档目录 resp-probe.mjs
:: 3. 逐页查控制接口
node %TEMP%\resp-probe\api-check.mjs           :: 脚本副本在归档目录 api-check.mjs
```

探针每页开独立 target，逐档做 `Emulation.setDeviceMetricsOverride`（1440×900 / 1280×800 / 1024×768 / 768×1024 / 375×812，375 档 `mobile:true`，其余 false）后重新导航，落定 2.2s，然后：

- 断言 `document.documentElement.scrollWidth <= document.documentElement.clientWidth`（实测全部严格相等，+1px 容差未参与判定）；命中时逐元素找越界者（本轮未触发）。
- `Page.captureScreenshot`（`captureBeyondViewport:true`）整页截图。
- 采集 `Runtime.exceptionThrown`、`consoleAPICalled(error/warning)`、`Log.entryAdded(error)` 全程事件。

数据文件：`99-archive/2026-10-03-响应式实测/响应式实测结果.json`（逐页逐档原始值）、`控制接口实测.json`；截图 63 张（每页 5 档整页图 + 1440 reduce 图 + scroll-bottom 视口图）。

375 档不用 `--window-size` 截图，按 gsap-probe 审记第六节的教训走 CDP 模拟，这点与前次结论一致。

## 五、prefers-reduced-motion 降级检查

方法：`Emulation.setEmulatedMedia` 置 `prefers-reduced-motion: reduce` 后重载，读 `body.innerText` 总量与 h1，与普通档对照；另存整页截图 `*.1440.reduce.png`。

| 页面 | 普通档载入 textLen | reduce textLen | 比值 | 判定 |
| --- | --- | --- | --- | --- |
| why | 455 | 1146 | 2.519 | PASS（reduce 更多，见口径说明） |
| glossary | 1227 | 1227 | 1.000 | PASS |
| ideas | 4494 | 4494 | 1.000 | PASS |
| field-notes | 2159 | 2159 | 1.000 | PASS |
| sandbox | 1476 | 1576 | 1.068 | PASS（同上） |
| limits | 1298 | 1298 | 1.000 | PASS |
| steal-this | 1364 | 1364 | 1.000 | PASS |
| open-questions | 3437 | 3437 | 1.000 | PASS |
| cordis-hero | 248 | 248 | 1.000 | PASS |

口径说明：普通档取的是「载入未滚动」时刻的文本量。滚动显影页在载入时把视口外内容藏起来（why 用 autoAlpha 含 `visibility:hidden`，`innerText` 不计入，故比值 2.519；glossary 卡片用纯 opacity，计入，故比值 1）。比值大于 1 的两页是 reduce 直出终态、普通档渐进显影的自然结果，方向是 reduce 侧内容更全，不构成缺失。why 的 reduce 整页截图目检：图 01 描线完整直出、87/7 终值直出、统计带与幕三文案全量可见，证实降级内容零缺失。

各页降级实现出处：`why.html:601`（gsap.matchMedia 包裹全部运动动画，reduce 回调不执行即停 CSS 终态）、`glossary.html:627-644`（reduce 直接加 `.in`，过渡样式整体收在 `no-preference` 媒体查询里）、`field-notes.html:429-431,730-734`（`no-anim` 类 + JS 早退置终值）、`sandbox.html:1054-1059`（播放钮改「查看终态/查看拔除中」双态淡切）、`limits:349-355` 的 CSS 强制终态 + JS 早退、`steal-this.html:467-469`（全局 `animation:none`）、`open-questions.html:370-375`（横幅直出、浮层只淡切）、`ideas.html` 无 JS 无从降级、`cordis-hero.html` 无动效。

## 九、hero 小样历史结论补证

定稿第 1 节依据 `cordis-hero.html:190-203` 记录「<960px 塌单栏不破版」，本轮为该结论补上浏览器实测：

- 375 档 `scrollWidth=375=clientWidth`，无横向滚动；整页截图见单栏（文案区在上、场景 SVG 在下，`grid-template-columns:1fr` 生效）。
- 768 档同规则生效，`753=753`；1024 档（>960）保持双栏，`1009=1009`。
- 断点行为与 CSS 声明一致：`@media (max-width:960px)` 内含页边距收 14px、报头换行、hero 塌单栏、headline 改 `clamp(32px,8vw,44px)`。

结论维持成立，从「代码审查成立」升级为「实测成立」。

## 十二、非失败观察项（记录，不判 fail）

1. **limits 图 01 的受控容器滚动**：<960px 时图解走 `.svg-scroll{ overflow-x:auto }` 且 SVG `min-width:640px`（`cordis-limits.html:368-369`），小屏可在容器内横向拖看图解。页面级 `scrollWidth` 不受影响（实测 375 档 375=375），这是保图可读性的降级设计，但它是全站唯一一个允许横向拖动的小屏部件。是否接受此形态，留给规则 4 复审裁决。
2. **整页截图伪影**：第八节已述，属测量方法限制，非页面缺陷。
3. **字号 token 偏离**：why 的 act 标题（58-76px）与 ideas 的 display（58px 起跳）、glossary/steal-this/open-questions 的移动端 58px 抬档，都超出通用词汇的 38-58px clamp 家族；各页的 5 倍跳变线均过，其中三页明确选了定稿给的「下限抬到 58px」档，why 未注明选档理由。
4. **ideas 注释与实现不符**：`ideas.html:843` 设计说明声称有「节间一次轻显影」，页面实际零 JS。见第十节该页末行。
5. **open-questions 带走物已填文案**，与他页空槽口径不一，M3 收口时统一。
