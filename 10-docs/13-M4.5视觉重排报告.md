## 1. 结论：四宗罪逐条回应

一段话总账：字小墨淡、卡片荒两罪在本版升级为独立复算与 9/9 页证据后判解决；无引导在钉住场景（首页、沙盒）闭环，why 页动效无指示器是否违约留上游界定；空白成瘾维持部分解决，DOM 实测 7/9 页达标、ideas 与 open-questions 两页超线 68% 与 33%，连续空白验收线仍无任何强制手段。

**字小墨淡：解决。** 代码层（global.css 实读）：正文 17.5px / 行高 1.9 / 100% 实墨（82-90，注释自带评审线「≥17px 且实墨」）；h1 clamp(44px,4vw,52px)、h2 28px、h3 20px 全部 serif 900 实墨（92-99）；大数字 48~56px（102-109）；--text-body 改指 var(--ink)（49-51）；幽灵字禁用验收线成文：≥24px 文字墨度不得低于 40%（80-81）。对比度独立复算【实读】：本会话自写 oklch→sRGB→WCAG 换算（node 一次性脚本），换算管线先以四个已知目录色自证，输出 #FAFAF7、#2148B8、#12151D、#A0B4EE 与 css 注释逐位吻合；复算小字浅 4.517:1、深 5.867:1，与上游实算 4.52/5.86 吻合（差异为舍入），正文实墨对比度浅 7.477、深 8.929。脆弱性明示：浅色小字裕量仅 0.017，技术上过线、工程上脆弱，是否升 --ink-80 档（css 注释口径 4.72:1）留上游裁决（§6.2-3）。计算样式实测【实读】（CDP 审计 9 页 × 4 视口，见 §5.1）：body 全站 17.5px / 33.25px / oklch(0.449 0.182 265)，h1 serif 实墨 44~52px，h2 28px 实墨。两处例外如实记：首页 375 视口 h1 实测 32px，低于全局阶梯下限（index.astro:174 桌面覆盖 clamp(44px,3.15vw,50px)，1440 实测 45.36px 与 3.15vw 吻合；32px 的移动端覆盖行未逐行定位，v2 §2 无移动端例外条款）；页首功能组件存在 11.5~13px 文字（导航 12、kicker 12、徽标 12、按钮 11、页脚 11.5，global.css 实读），v2「14px 唯一降档」未给 UI 功能文字档位。审计局限：正文段抽样取 main 首个 p，首页/why/借鉴/答问四页命中的是页首小字组件（12~14px）而非正文段；body 继承 17.5px 与词典/思想/边界页 p 实测 17.5px 实墨支撑正文结论，逐组件字号普查未做。
