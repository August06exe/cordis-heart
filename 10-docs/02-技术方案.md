## 2. 设计读数（定调，实现时不许漂移）

- Design Read：面向 Vibe Coder 的教育型编辑风站点，单墨印刷语言，动效向苹果式滚动叙事看齐。
- 三旋钮：`DESIGN_VARIANCE 7`（非对称双栏、编辑排版，<768px 一律塌成单栏）、`MOTION_INTENSITY 8`（钉住擦洗、可倒放可重播）、`VISUAL_DENSITY 3`（画廊式留白）。
- 单墨体系：背景纸白 `#FAFAF7`，唯一墨色钴蓝 `#2148B8`。熄灭态与次要信息用透明度阶梯 100% / 60% / 30% / 12%；**60% 档仅限大字号与装饰元素，正文与次要信息一律 100% 墨**——钴蓝 60% 对纸白实测对比度 3.02:1，低于 AA 正文线 4.5:1（2026-10-02 M1 实测，待办 a）。全站一种色相，插图与图表同墨。
- 反 AI 味设计禁令：无紫色渐变与霓虹发光、无玻璃拟态滥用、无三等分卡片阵列、无「滚动探索」类提示语、无破折号装饰、无装饰性状态圆点、无 `Scroll to explore`。

## 3. 动效四配方

苹果式网页动画拆开就这四样，全部用 GSAP + SVG 实现：

1. **滚动擦洗（scrub）**：动画进度绑在滚动位置上，滚多少放多少，倒滚倒放。用于首页英雄叙事和章节过场。
2. **钉住（pin）**：段落钉在视口内，滚动只推进动画，滚完放行。`start: "top top"`，钉住终点由叙事长度决定。
3. **总时间轴（timeline）**：每个场景一条主时间轴，可暂停、可变速、`restart()` 即重播。重播按钮调用它。
4. **只动 transform 和 opacity**：保证 60fps。唯一例外是 SVG 描边动画的 `stroke-dashoffset`。**已知风险与备选**：GSAP 对内联 SVG 写的是 transform 属性（attr 矩阵）而非 style，属性变更在 Blink 走布局——CDP 实测播放窗口 Layout 153 次（空闲为 0）。若真机 60fps 验收不达标，场景改用 CSS transform 或 DOM 积木实现（2026-10-02 M1 实测，待办 b）。

## 4. 首页英雄叙事（规格）

布局：桌面端左 40% 文案区、右 60% 场景区；移动端上下堆叠、场景等比缩放。场景为内联 SVG，几何形体，不拟物：一块「运行基座」横条（墨色 12% 透明度），上面立 5 个组件积木（圆角矩形、2px 描边、纸白填充、内有一行小字）：中央「数据库驱动」是提供者；右侧「聊天插件」「查询插件」各有一条贝塞尔依赖线连向它；左侧「主题皮肤」「日志器」无依赖线，是独立组件。

叙事五拍与滚动映射：

| 拍 | 滚动区间 | 内容 |
| --- | --- | --- |
| 一、装上 | 0–20% | 五块积木从基座下方依次浮入落位（stagger），依赖线用描边动画逐一画出 |
| 二、拔掉 | 20–45% | 文案切到「拔掉它」；「数据库驱动」被抬起抽出基座 |
| 三、连锁熄灭 | 45–70% | 两个依赖积木依次熄灭（降为 12% 透明度并微微下沉），依赖线虚化断裂；独立积木保持点亮：只影响声明过的依赖 |
| 四、复原 | 70–95% | 提供者归位，熄灭积木依次复明，依赖线重新画出：原样退回去 |
| 五、定格 | 95–100% | 标题「让运行中的软件换零件，还能原样退回去」落定，场景角出现「重播」按钮 |

细节要求：主时间轴 `scrub: 0.5` 配 pin；重播按钮点击即 `tl.restart()`；`prefers-reduced-motion: reduce` 时跳过钉住擦洗、直接渲染终态，重播按钮改为**终态与拔除中态之间淡切**（本叙事终态等于初始态，按"终态与初始态淡切"实现按钮会无效果——2026-10-02 M1 实测，待办 c）；文案不超过一条标题加一句副文，不出现滚动提示语。

## 5. 五个交互演示规格

| 演示 | 形态 | 规格 |
| --- | --- | --- |
| 撤销堆栈 | DOM + GSAP 时间轴 | 三个动作按钮（注册事件、开定时器、建连接），每按一次压入一张动作卡并播放正向效果；「撤销」按 LIFO 弹栈并回放逆动作；「全部重置」等于累加器一次清账。侧栏一句话注解：每个动作自带撤销说明书 |
| 组件插拔模拟器 → 组件沙盒 | SVG + GSAP，Rive 试水候选 | 已拍板升级为全功能沙盒（PRD 6.1）：可拖拽建依赖、热替换提供者、看连锁熄灭与换源复明；是首页之外唯一的全力炫位，规格 M5.5 开工前单独评审 |
| 万物过前台 | SVG 路径动画 | 组件的所有操作画成小方块沿路径流经同一个「前台」柜台，柜台账本逐笔记账；GSAP MotionPath 驱动 |
| 搬箱子（交换性） | SVG 分屏对比 | 左右两屏同一组箱子按不同顺序搬运，终点货架完全一致；一句注解：顺序无关，才敢随便拆 |
| 生命周期状态机 | DOM 状态机 | 装上、在岗、停用中、空闲四态按钮可手动触发，断供场景演示依赖连锁；核心是「停用中」那拍的等待感 |

原则：宁做一个小而真的，不做五个大而假的。每个演示深度在 M2 逐个评审后定。

## 6. 工程红线（写代码前后都查）

- 只动画 `transform` 与 `opacity`；SVG 描边动画的 `stroke-dashoffset` 是唯一例外。
- 禁止 `window.addEventListener('scroll')`；滚动逻辑只走 GSAP ScrollTrigger、IntersectionObserver 或 CSS 原生滚动动画。
- 禁止视频文件。一切动画必须是代码或矢量资产，可重播、可暂停。
- 每个动画场景对外暴露 `play() / pause() / restart()` 三个方法。
- `MOTION_INTENSITY` 高于 3 的动效必须尊重 `prefers-reduced-motion`，降级为静态终态且内容不缺失；站点提供手动「减少动效」开关；降级实现统一用 gsap.matchMedia 包裹运动查询（GSAP a11y 官方配方），大位移动画降为轻交叉淡。
- 场景滚出视口即暂停动画逻辑；`will-change` 只加在真正要动的元素上。
- 站点文案逐篇过 humanizer，中文说人话，类比优先于定义。
- 性能预算（PRD v0.3 拍板）：Lighthouse Performance ≥ 90，首页与沙盒两个重动画页 ≥ 85；LCP < 2.5s；动画全程 60fps，验收实测。
- 验收清单：控制台无报错；滚动到底再倒滚全程正常；手机宽度不破版；全页单一色相；每个场景重播可用。

## 8. 原型与移植策略
