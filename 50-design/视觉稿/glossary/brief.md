## 2. 页面内容素材：十张术语卡（逐卡文案如下，可微调标点，不得改动事实与出处）

页面信息带文案：

- kicker：`通俗词典 · 十个术语`（本页唯一 kicker，12px / 字距 .42em / 墨 .78）
- 大标题（Noto Serif SC 900，58px 固定）：`术语说人话`
- 副文（16px/2.0，墨 .82，列宽 ≤26em）：`按重要程度排，够用为准。每张卡三段：大白话定义、生活类比、论文出处。`
- 网格前 microcopy（11.5px，墨 .78）：`悬停或 Tab 聚焦卡片，查看类比与出处`
- SVG 图注（11.5px，墨 .78，前置 1px 细线）：`图 01 · 语境是唯一的门`

十张卡（条目号 01-10 为功能编号，被图注与浮层引用，豁免「节号眉标禁令」；条目号与英文术语用 IBM Plex Mono）：

**01 · effect · 效应**
- 定义：程序对外部世界留下的改动，写文件、开端口、注册一条命令都算。论文要求每个效应自带撤销办法。
- 类比：装修留收据。工人每动一处，当场留一张「如何复原此处」的说明，房东退租时按相反顺序执行一遍。
- 出处：论文 arXiv:2608.25512；对应 Cordis 的 `ctx.effect()`，装上去的每样东西都留撤销按钮。徽标：论文原文核实（实印）。

**02 · coeffect · 反效应**
- 定义：效应的镜像。效应说「我对世界做了什么」，反效应说「世界得先给我什么」：资源、权限、服务。说白了就是依赖清单。
- 类比：餐馆门口挂牌「本店需要水、电、燃气」。市政停水那一刻，挂牌状态翻转，餐馆自动贴出暂停营业。
- 出处：论文 arXiv:2608.25512；对应 dsh 的 `inject` 依赖声明，写明我要什么，框架等就绪才启动。徽标：论文原文核实（实印）。

**03 · context · 语境**
- 定义：全系统共用的一本大账，记着当前状态、所有撤销办法、所有依赖登记。组件和环境的每一次交互都经过它，谁也不许绕开。
- 类比：酒店前台的总账。住客想动任何东西都得记在总台账上，谁也不许私下配钥匙。
- 出处：论文 arXiv:2608.25512；对应 `ctx` 对象与 `ctx.*` 稳定键（tools、llm、fs、sandbox、sessions 等）。徽标：论文原文核实（实印）。

**04 · component · 组件**
- 定义：一份岗位说明书，含三份文件：我需要什么、我能提供什么、我上岗后干什么（每件事附撤销办法）。
- 类比：就是岗位说明书本身：任职要求、能提供的职责、上岗后的工作清单，三份文件一次交齐。
- 出处：论文 arXiv:2608.25512；对应 Plugin / Service，插件就是组件的实现形态。徽标：论文原文核实（实印）。

**05 · fiber · 纤维**
- 定义：说明书的一次具体上岗。组件是职位描述，fiber 是某年某月入职的那位员工，从入职到离场有固定流程。
- 类比：同一份职位描述，每雇一个人就对应一个 fiber；入职、在岗、离职走同一套流程，谁也不能私下改。
- 出处：论文 arXiv:2608.25512。注记：dsh 文档未出现此词，隔离角色由 scope 承担（研读存疑项之一）。徽标：主出处论文原文核实（实印）；注记挂合理解读（网屏）。

**06 · revertible · 可逆**
- 定义：改动的附赠品。谁做的改动谁当场交出撤销函数，运行时统一保管，卸载时按后进先出执行。
- 类比：Ctrl+Z 的历史栈。后发生的先撤销；所有撤销函数串成一个累加器，像按一次键全退光。
- 出处：论文 arXiv:2608.25512；对应 `ctx.effect()` 加 disposer，文档称「可回退注册」。徽标：论文原文核实（实印）。

**07 · reactive · 响应式**
- 定义：依赖是活的。环境每变一次，运行时拿每个组件的需求清单对照一遍：从缺到齐就激活，从齐到缺就停用，其余不理会。
- 类比：夜市摊位接隔壁摊的电源。隔壁收摊你自动歇业，隔壁回来你自动开张，不用雇人二十四小时盯着电闸。
- 出处：论文 arXiv:2608.25512；对应 `inject` 依赖声明，插件自己不找依赖，也不写监控代码。徽标：论文原文核实（实印）。

**08 · 声明式配置 · declarative config**
- 定义：用一份配置树描述「系统应该长什么样」，加载器负责把现实改成和清单一致，改动按最小动作分发，不推倒重来。
- 类比：手动挡与自动挡。使用者只写愿望清单，加载器把现实改成和清单一致，改多少算多少。
- 出处：论文 arXiv:2608.25512；对应 Profile、Bundle、Patch 三层组装，`cordis.patch.yml` 按 id 替换任意配置行。徽标：论文原文核实（实印）。

**09 · HMR · 热模块替换**
- 定义：改了源码文件，程序不重启，原地换掉受影响的零件。Cordis 的重载是事务性的：先备份，失败整体回滚，永不半新半旧。
- 类比：先备份再换件。装修换壁纸，旧壁纸完整收好，新的贴失败就原样贴回去，绝不留半面新半面旧。
- 出处：论文 arXiv:2608.25512；Cordis 的 hmr 配套模块（dsh 将 loader、hmr 等配套整体 vendor 进仓库）。徽标：论文原文核实（实印）。

**10 · 生命周期 · lifecycle**
- 定义：一个零件从装上到拆下经过的固定阶段。论文里 fiber 有四态：空闲、激活中、在岗、停用中，怎么流转由九条规则管。
- 类比：拆迁先疏散租户，确认全走了，再动承重墙。停用一台数据库时，先宣布停机，等所有依赖方安全拆完，自己才倒序撤销。
- 出处：论文 arXiv:2608.25512；九条规则：人只下三道命令（插入、退役、移除），其余六条是系统自动流转。徽标：论文原文核实（实印）。

可靠度徽标只做两档（实印 / 网屏），用**墨的密度**区分（实心实印 vs 网点网屏），不引入第二色相，不带文字说明时用 `aria-label`。本页不出现第三档（转引未核实）。

2. **主区结构**：报头之下为信息带（kicker + 大标题 + 副文 + 图注线），其下为术语卡网格，其下为 SVG 图解（或图解与信息带左右并置，见第 4 节），最下为设计说明 + colophon（`deepseek-harness / Cordis 支撑框架`、`视觉稿 · 单墨编辑印刷`）。

4. **卡片形态**：采用「细线信息带」式条目：上下 1px 墨 .20 细线分隔成排，不做圆角盒卡阵列、不做填充底色；整卡可聚焦（键盘 Tab 可达）。卡面：条目号 + 英文术语（IBM Plex Mono，编号可用墨 .80）+ 中文术语（Noto Serif SC 900，约 24-28px，实墨）+ 大白话定义（16px/1.9-2.0，墨 .82）。浮层内：定义重述 + 生活类比 + 论文出处三段（类比与出处 15-16px，墨 .78/.82），段落自含、可整段复制。
5. **字号跳变**：display 对本页最小功能字（11.5px 图注 / microcopy）≥5 倍。**裁定：本页 display 全程 58px 固定**（58 / 11.5 = 5.04 全程过线），不走「clamp 下限档豁免」路线。
6. **留白**：空纸 25%~50%，信息带与网格之间、两列之间保持大留白；对齐左缘或 2 列编辑网格；全部元素居中是失败形态。
7. 图标仅在有真实语义处使用，且只许 Phosphor / HugeIcons / Radix / Tabler 之一；本页预计不需要图标。

## 5. 动效分镜（页级强度 5：浮层与轻入场，除此之外页面安静）

页面无钉住、无滚动擦洗、无滚动提示语；只动 `transform` 与 `opacity`。

1. **第 1 拍 · 进场（唯一编排时刻）**：卡片按条目号顺序 stagger 约 60ms、位移 ≤12px 的一次性上浮淡入（IntersectionObserver 触发一次，此后不再动）。页面 load 本身无其他动画。
2. **第 2 拍 · hover 翻转与浮层**：hover 或键盘 focus 目标卡时，浮层经 **@floating-ui/dom** 定位：`offset(8)` + **`flip()`（视口边缘自动翻转，即 brief 所称 hover 翻转）** + `shift()`（防溢出）。浮层淡入并轻上浮 8px，约 160ms ease-out；宽约 280-340px；2px 墨线勾勒、纸白底、投影可用墨 .20 细影。
3. **第 3 拍 · 浮层三段显影**：大白话定义、生活类比、论文出处三段依次淡入（各间隔约 80ms，位移 2-4px）。
4. **第 4 拍 · 收场**：鼠标移出 / 失焦 / 点击浮层外 / 触屏再次点按时浮层淡出约 120ms，无弹跳、无缩放过冲。
5. **触屏**：无 hover，点按切换浮层；同一时刻至多一个浮层开启。
6. **降级红线**：`prefers-reduced-motion: reduce` 时进场动效与浮层动效全部取消（直显 / 直切），内容零缺失，floating-ui 定位保留；`@floating-ui/dom` CDN 加载失败时降级为 CSS 简单定位，控制台零报错。

## 7. 出稿自检清单（交付前逐条执行，结果随交付说明带回）

可脚本项（node，在本页文件上实跑）：

1. **单色相扫描**：提取全文 hex 与 oklch 色值；色度 C ≥ 0.02 的色值必须同属钴蓝色相（OKLCH H = 265 ±5°）；C < 0.02 视为中性基底豁免（纸白 C=0.004 走此门）。
2. **WCAG 对比度**（8-bit 合成口径）：alpha 令牌先在 sRGB 上对纸白合成再算相对亮度；文字档 .78/.80/.82 ≥4.5、图形线 .70 ≥3；.14/.20 不得出现在任何文字色。
3. **禁令 grep**：`—|–` 零命中；`scroll to explore`（忽略大小写）零命中；`linear-gradient|backdrop-filter|blur\(` 零命中；`#000000` 零命中；`h-screen` 零命中；`·` 每行 ≤1。

人工项：

4. 无三等分卡阵；无装饰性状态圆点（徽标网点如用圆点须承载真实语义且每节 ≤1）；进场动效是全页唯一非用户触发的编排。
5. 四档视口无横向滚动；`prefers-reduced-motion` 降级后内容不缺失；控制台零报错。
6. 内容覆盖：十张卡全在、每卡三段全在、图解一幅、设计说明一段、报头 / 图注 / colophon 齐。

对比度与色相可参考如下 node 脚本起步（可直接扩展成第 1、2 条的完整检查）：

```js
// check.js — node check.js glossary.html
const fs = require('fs');
const html = fs.readFileSync(process.argv[2] || 'glossary.html', 'utf8');

// 1) hex 白名单扫描（oklch 令牌按既有取值人工核对：0.449 0.182 265[/a] 与 0.984 0.004 106.5）
const hexes = [...html.matchAll(/#[0-9a-fA-F]{3,8}\b/g)].map(m => m[0].toUpperCase());
const allowed = new Set(['#FAFAF7', '#2148B8']);
const bad = [...new Set(hexes)].filter(h => !allowed.has(h));
console.log('非白名单 hex:', bad.length ? bad : '无');

// 2) alpha 档对纸白对比度（8-bit 合成，WCAG 相对亮度）
const fg = [0x21, 0x48, 0xB8], bg = [0xFA, 0xFA, 0xF7];
const mix = a => fg.map((v, i) => Math.round(v * a + bg[i] * (1 - a)));
const lum = ([r, g, b]) => {
  const s = [r, g, b].map(v => { v /= 255; return v <= 0.03928 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4; });
  return 0.2126 * s[0] + 0.7152 * s[1] + 0.0722 * s[2];
};
const cr = (c1, c2) => { const [a, b] = [lum(c1), lum(c2)].sort((x, y) => y - x); return (a + 0.05) / (b + 0.05); };
for (const a of [1, 0.82, 0.80, 0.78, 0.70, 0.20, 0.14])
  console.log(`墨 ${a}: ${cr(mix(a), bg).toFixed(3)}:1`);
```

预期输出（上游已实测基准，本次撰写时已逐档手工复核）：1 → 7.48（实墨）、.82 → 4.966、.80 → 4.716、.78 → 4.524、.70 → 3.778、.20 → 1.39、.14 → 1.25。

## 8. 一句话气质（brand-spec 原文）

一张只有钴蓝墨水的印刷版画：衬线立骨、留白呼吸、几何图解说架构。词典页是全站的**索引柜**：安静、快进快出，查一个词就像抽一张档案卡。
