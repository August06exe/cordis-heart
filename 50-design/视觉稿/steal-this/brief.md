# 出稿 Brief：/steal-this 借鉴清单 · 抄作业生成器

单页视觉稿（单文件 HTML），风格：单墨编辑印刷。本页是「抄作业生成器」的界面稿：左侧 15 条可借鉴思想做成可勾选清单，右侧生成器面板实时拼装出可复制给 AI 的 markdown。

## 0. 交付物

- 一个单文件 HTML 视觉稿，文件名建议 `steal-this.html`，可引用 Google Fonts CDN，其余资源全部内联。
- 至少一幅内联 SVG 图解（见 §2.3）。
- `</body>` 前附一段 HTML 注释形式的设计说明：配色 / 字体 / 构图 / 动效分镜各一两句；其中必须写明移动端 display 字号走了哪条口径（见 §6.6）。
- 交互用 vanilla JS 实做（几十行以内即可），不引入任何构建工具或运行时依赖。
- `<title>` 建议「Cordis 思想图鉴 · 借鉴清单」，全页可见文本（含 title、按钮、alt、生成器内 markdown）零破折号。

## 1. 风格铁律（逐条强制，评审按此打分）

1. **单墨编辑印刷风**：纸白 `#FAFAF7` 背景，全页唯一墨色钴蓝 `#2148B8`，层次只靠透明度阶梯（.14 基座 / .20 细线 / .70 图解线 / .78 小字 / .82 正文 / 1 标题），不出现第二色相。
2. **对比度红线**：文字对纸白 ≥4.5:1（用 node 实算 WCAG，不许目测），图解线 ≥3:1；淡墨 .14 / .20 只用于色块与细线，不用于文字。勾选框这类承载状态的 UI 描边按图形线 ≥3:1 执行（用墨 .70 或实印，不用 .20）。
3. **字体**：Noto Serif SC 900 衬线大标题 + Noto Sans SC 正文（400/500/700）；生成器预览与编号用 IBM Plex Mono。留白占 25%~50%。
4. **反 AI 味五禁令**：无紫色渐变、无玻璃拟态、无三等分卡片阵列、无「滚动探索 / Scroll to explore」提示语、无装饰性状态圆点。
5. **交付物形态**：单文件 HTML、内联 SVG 图解、末尾设计说明。

### 1.1 色彩令牌（原样继承首页小样，直接抄）

:root{

  --fg:     oklch(0.449 0.182 265);       /* 全页唯一墨色：钴蓝 #2148B8 */
  --ink:    var(--fg);
  --ink-14: oklch(0.449 0.182 265 / .14); /* 浅墨 · 基座 / 高亮闪 */
  --ink-20: oklch(0.449 0.182 265 / .20); /* 分隔细线 */
  --ink-70: oklch(0.449 0.182 265 / .70); /* 图解线 · ≥3:1 */
  --ink-78: oklch(0.449 0.182 265 / .78); /* 小字 / 注脚 · ≥4.5:1 */
  --ink-82: oklch(0.449 0.182 265 / .82); /* 正文 · ≥4.5:1 */
  --serif: "Noto Serif SC","Songti SC","SimSun",serif;
  --sans:  "Noto Sans SC","PingFang SC","Microsoft YaHei",sans-serif;

### 1.2 版面基准（沿用首页小样 cordis-hero.html 的已验证规则）

- 印刷开本：页面四缘一圈 1px 墨线框（墨 .20），页边距桌面 22px、移动 14px；报头、正文、页脚三段以 1px 分隔线切开。
- 报头：左侧 wordmark（CORDIS 衬线 900 + 「DSH 的心脏 · 思想图鉴」小字），右侧 folio 章节名「借鉴清单 · STEAL THIS」。
- kicker：12px、字距 .42em、墨 .78；大标题 clamp(38px, 3.6vw, 58px) 衬线 900；正文 16px / line-height 2.0、墨 .82、列宽上限 26em；图注 11.5px 配 1px 细线。
- SVG 图解语言：2px 描边、纸白填充、rx 10 圆角积木，立于墨 .14 基座条上；依赖 / 流向用 1.6px 贝塞尔曲线加箭头（墨 .70）。
- 留白：空纸 25%~50%，主对象四周露纸，对齐左缘或编辑网格；全部元素居中是失败形态。
- 无障碍：`:focus-visible` 2px 墨色外框；满高用 `min-height:100dvh`，禁 `h-screen`。

## 2. 页面内容与布局

### 2.1 结构（自上而下）

1. **报头**（见 §1.2）。
2. **标题带**：kicker「第五节 · 可借鉴思想」+ 衬线大标题 + 一句副文。建议标题「十五条思想，勾走你要的」，副文（可微调，守禁令）：「左侧勾选用得上的条目，右侧自动拼出一份 markdown 清单。复制给任何 AI 或工程师，都能照单执行。」标题带右侧或下方放流程图解（§2.3）+ 图注。
3. **主区双栏工作台**（非对称分栏，建议 58fr 42fr 或 60fr 40fr，禁对半）：

4. **页脚 colophon**：左「deepseek-harness / Cordis 支撑框架」，右「单墨编辑印刷 · 思想图鉴」。

本页的生成器就是全站「带走物」本体，页尾不再另设带走物块。

### 2.2 清单行 anatomy（每条）

- 自定义复选框：未选 = 1.5~2px 墨 .70 描边方框（≥3:1）；选中 = 实印墨填充 + 纸白勾。
- 编号 01~15：mono 10~11px、墨 .78；选中态转实印。
- 标题：Noto Sans SC 700，15~16px，实印或 .82。
- 说明一句：14~15px、墨 .82。
- 出处行（第 2 轮修订，完整规格见 §8）：行首可靠度徽标（12px 小方标，三级墨密度形态）+ 出处小字 11.5px、墨 .78，如「思想一」「论文第 6 章」（来源见 §3 括注）；徽标支持 hover / 键盘 focus 弹出依据浮层占位。
- 选中行「点亮」的表达（单墨体系内）：行左缘或整行边框由 .20 细线转为实印 2px，编号与复选框转实印，不加底色块、不引第二色相。
- 真实 `<input type="checkbox">` + `<label>`，可键盘操作，`:focus-visible` 墨框。

### 2.3 内联 SVG 图解（一幅）

「勾选 → 拼装 → 带走」三步流程：三块 rx 10 圆角积木（2px 描边、纸白填充）立于墨 .14 基座条，块间用 1.6px 贝塞尔箭头连接（墨 .70），块内标签用实印或 .80 档墨。图注沿用小样三段式：`图 01` + 1px 细线 + `生成器三步`。图解是叙事件不是装饰件，宽高比服从标题带构图，不与标题抢位。

### 2.4 生成器预览面板 anatomy

- 面板头：小字「生成器预览」+ 真实计数「已选 3 条」（随勾选实时变化；这是真实计数，不属虚构数字）。
- 面板主体：`<pre>` IBM Plex Mono 约 13px、墨 .82，随勾选逐条拼出 markdown 块。块格式示例（每行至多 1 个中点）：

  ```

  ### 01 给每个注册动作配一个撤销函数
  装工具、挂监听器、注册命令的 API 都返回 undo……
  （出处：思想一）
  ```

- 空态：一条 .78 小字提示，如「勾选左侧条目，这里逐条拼出可带走的清单」。
- 面板底：两个按钮「复制」「下载 .md」，2px 墨线勾勒，hover 反白（实印底 + 纸白字）。「复制」点击后按钮文字就地切成「已复制」，两秒后切回。

## 3. 清单内容（逐字使用，括注为出处小字）

1. **给每个注册动作配一个撤销函数**：装工具、挂监听器、注册命令的 API 都返回 undo，卸载、热重载、权限回收全走这一种操作。（思想一）
2. **把能力挂在公共上下文的稳定键名下**：学 dsh 的 ctx.tools、ctx.llm，插件只认键名，不 import 具体实现。（第四节对应表）
3. **按「接口 + 提供者 + 消费者」三件套设计能力接缝**：换文件系统实现时让 shell、终端这些依赖方整体跟随。（第四节对应表）
4. **让插件进门先声明依赖清单**：依赖不齐就安静待机，等就绪自动激活，不报错也不轮询。（思想二）
5. **用永不复用的编号识别提供者**：货可以一样，人不能认错；宁可偶尔多重启一次，也不让下游带着已经易主的依赖继续跑。（思想五）
6. **状态只记一本账**：哪些能力可用，直接从「谁在岗」推出来，别再养一份可能对不上的资源名册。（思想四）
7. **把「改配置等于退役加重插，终态等于按新配置从头装一遍」立为运行时改动的目标性质**：前提是共享状态都守着走语境的纪律。（思想四、第六节）
8. **热重载做成事务**：先备份旧模块再换新，任何一步失败整体回滚，系统永不半新半旧。（思想五）
9. **把会话日志做成唯一事实源**：模型可见即已记录，只追加、永不改名删除，界面、回放、调试都从它投影。（第四节）
10. **权限跟着声明走**：插件只能读到它声明过的依赖，加载前就能审完整清单。（论文第 6 章）
11. **审一遍接口承诺**：没人依赖的返回值约定（比如「必须发最小的空号」这类）能砍就砍，换来操作可乱序、可独立撤销。（思想三）
12. **一个资源只允许一个提供者**：第二家申报同名资源直接拒绝，出了问题永远找得到人。（论文第 4 章）
13. **卸载次序立成协议**：先停供、通知依赖者、等它们全部拆完，自己再按后进先出清理。（思想四）
14. **失败显式记录原因、不自动重试、不传染邻居组件**。（论文第 4.4 节）
15. **给多租户或多 agent 场景加一层作用域隔离**：同名依赖各拿各的，撤销时丢掉整层即可。（思想三、dsh 的 scope）

## 4. 动效规格（页级强度 4）

定位：生成器即时反馈页。15 条清单与预览面板**载入即全量在页**，用户操作只做点选反馈与既有内容增补；没有藏进操作之后的核心内容，所以落 4 不落 5。**页面没有任何滚动驱动效果**：禁 pin、禁 scrub、禁视差、禁循环动画。

- **载入**（全页唯一非用户触发编排时刻）：标题带与清单一次性显影，淡入 + 位移 ≤12px，总时长 <800ms，stagger ≤60ms；也可以完全不做载入动画，二选一。
- **勾选一条**：清单行点亮（§2.2）；右缘面板实时追加对应 markdown 块：淡入（opacity 0→1，translateY ≤8px，约 240ms）加一瞬高亮（ink .14 的叠加层一闪后 600ms 内退去；高亮用叠加层 opacity 实现，保持只动 transform/opacity）。
- **取消勾选**：对应块淡出移除，余下块顺序与编号保持。
- **复制**：按钮文字就地切「已复制」，2s 后切回。
- 状态切换的 CSS 颜色 / 透明度过渡（120~160ms）属状态反馈，不计入动效预算；任何位移类动画只用 transform / opacity，60fps。
- `prefers-reduced-motion`：全部落到即时状态切换，内容不缺失。
- 本页无自动播放时间轴，无需重播入口。

## 5. 反 AI 味禁令（评审逐条 grep / 人工查）

1. 无紫色渐变、霓虹发光、玻璃拟态：`linear-gradient`、`backdrop-filter`、`blur(` 零命中。
2. 无三等分卡片阵列：清单两列锯齿，数卡片列不得出现三列等宽卡盒。
3. 无「滚动探索」类提示语：`scroll to explore`、`↓ scroll`、滚动提示、节号滚动提示，全部禁。
4. 无破折号：`—` 与 `–` 在全部可见文本（含 `<title>`、按钮、alt、生成器内 markdown）零出现；连字符 `-` 与数学负号除外。
5. 无装饰性状态圆点：圆点只在承载真实语义状态时允许，每节至多一个；本页建议一个都不用。
6. 中点限流：任何一行可见文本里 `·` 至多 1 个，禁止「foo · bar · baz」串联。
7. 禁装饰节号眉标（「002 · Capabilities」「Brand · No.01」式）；功能编号豁免：清单编号 01~15、图注「图 01」属功能编号，可用。
8. 禁虚构完美数字：本页唯一的数字是真实勾选计数（已选 n 条）与清单编号。
9. 非用户触发的动效每页只允许一个编排时刻（§4 载入）；眉标（kicker）全页至多一个。

## 6. 工程与无障碍红线

1. 单文件 HTML，`lang="zh-CN"`，viewport 正常设置，无外部 JS / CSS 依赖（Google Fonts 除外）。
2. `min-height:100dvh`，禁 `h-screen`；报头单行高 ≤80px。
3. 响应式：视口 375 / 768 / 1280 / 1440 四档无横向滚动（`scrollWidth <= clientWidth`）；<960px 塌单栏（清单在上、面板在下），页边距收 14px。
4. `:focus-visible` 2px 墨色外框；checkbox 可键盘操作（Tab + Space）。
5. 复制用 `navigator.clipboard`，失败或 file:// 受限时静默降级为选中文本，按钮态演示逻辑不变。
6. 字号跳变：display（58px）对本页最小功能字（11.5px）≥5 倍。移动端二选一：display 下限抬到 58px（全程过线），或维持 38px 并在设计说明里标注「clamp 下限档豁免」。走了哪条必须写明。
7. `::selection` 用墨 .14（沿小样）。
8. 可沿小样惯例给主要区块标 `data-od-id`。

### 8.3 徽标形态（单墨体系内的三级墨密度）

- 形态：出处行行首一枚 12px 见方小方标（与复选框同族、更小号，直角或 rx 2），后接出处文字。三级用墨的密度区分（印刷隐喻：实印 / 网屏 / 细线）：
