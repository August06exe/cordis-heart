# 视觉稿 brief：/sandbox 组件沙盒（全力炫位二）

产出一份单文件 HTML 视觉稿，落在本 brief 同目录（文件名建议 `sandbox.html`）。这是一个满高工作台界面稿加一段完整交互分镜，是全站与首页并列的两个全力炫位之一。上游出处：PRD 6.1「组件沙盒模拟器」、02-技术方案 第 5 节「组件插拔模拟器 → 组件沙盒」、04-DesignRead-定稿 第 2 节 /sandbox brief；风格实样参照 `50-design/03-首页小样-OD/cordis-hero.html`（token 与积木画法照它继承）。

## 1. 风格铁律（逐条必须满足，评审按此打分）

1. **单墨编辑印刷风**：纸白 `#FAFAF7` 背景，全页唯一墨色钴蓝 `#2148B8`，层次只靠透明度阶梯（.14 基座 / .20 细线 / .70 图解线 / .78 小字 / .82 正文 / 1 标题），不出现第二色相。
2. **对比度红线**：文字对纸白 ≥4.5:1，图解线 ≥3:1；淡墨 .14/.20 只用于色块与细线，不用于文字。以下为 node 实算 WCAG 的已验证值（alpha 先在 sRGB 上按 8-bit 合成再算，可直接引用，不必重算）：

   | 令牌 | 对纸白 | 用途 |
   |---|---|---|
   | 墨 1.00（#2148B8） | 7.483:1 | 标题、积木描边与标签（实印） |
   | 墨 .82 | 4.966:1 | 正文、动作日志 |
   | 墨 .80 | 4.716:1 | 图内编号小字 |
   | 墨 .78 | 4.524:1 | 小字注脚、folio |
   | 墨 .70 | 3.778:1 | 依赖线、箭头（表意图形线 ≥3:1） |
   | 墨 .20 | 1.389:1 | 分隔细线（装饰豁免） |
   | 墨 .14 | 1.251:1 | 基座色块、熄灭块（装饰豁免） |

3. **字体**：Noto Serif SC 900 衬线大标题 + Noto Sans SC 正文（400/500/700）；数据与日志场景用 IBM Plex Mono。display 对本页最小功能字（11.5px 图注）字号跳变 ≥5 倍（58/11.5=5.04）。留白占 25%~50%，中央画布大部分保持空纸。
4. **反 AI 味五禁令**：无紫色渐变、无玻璃拟态、无三等分卡片阵列、无「滚动探索/Scroll to explore」提示语、无装饰性状态圆点。
5. **交付物形态**：单文件 HTML 视觉稿（可引用 Google Fonts CDN），内联 SVG 图解，末尾附一段设计说明（配色/字体/构图/动效分镜各一两句）。

## 2. 页面定位

- `/sandbox` 组件沙盒，动效强度 8，九页里唯一「滚动少、手上多」的页面；深链自 `/ideas`（PRD 第 5 节）。
- 一句话：站内做一个迷你 Cordis——拖「提供者」「消费者」积木、连依赖线，热替换一个提供者，亲眼看着依赖它的积木逐个熄灭、换源复明，再原样装回去。纯前端状态机示意，不执行任何真实代码。
- 页面标题（`<title>`）建议「DSH 的心脏 · 组件沙盒设计稿」。

## 3. 布局规格（满高工作台）

- 满高 `min-height:100dvh`（禁 `h-screen`）。页面四缘一圈 1px 墨 .20 细线框（印刷开本），页边距桌面 22px。
- **顶部工具栏** ≤80px 单行，1px 墨 .20 底边线：左 wordmark「CORDIS」（Serif 900、字距 .34em）+「组件沙盒」小字（Sans 500、13px、字距 .18em、墨 .82）；右 folio「SANDBOX · 组件工作台」（12px、字距 .22em、墨 .78）。
- **三栏工作区**：左积木托盘（约 220px）｜中央画布（自适应，最大留白区）｜右状态侧栏（约 280px）。栏间 1px 墨 .20 分隔线。面板一律 2px 实墨线勾勒、纸白填充，不做填充色区分。
- **底部控制条**（工作台 chrome，1px 墨 .20 顶边线，高约 64px）：左侧按钮组「播放六拍 / 暂停 / 重播 / 复原」——2px 墨线勾勒按钮、纸白底、hover 反白为实墨底纸白字；右侧提示「Ctrl+Z 撤销 · 优先交给沙盒撤销栈」（11.5px、墨 .78；注意此行间隔号至多 1 个）。
- 工作台之下是**页面第二屏：六拍交互分镜带**（静态交付文档）。分镜带上方给 display 级标题（Serif 900、`clamp(38px, 3.6vw, 58px)`、line-height 1.32）如「六拍，讲完一次热替换」，配 kicker 一枚（12px、字距 .42em、墨 .78）。六格横排或 3×2 两行，格内为该拍画布的静态 SVG 快照，配「分镜 01」式功能编号（编号被图注引用，属功能编号豁免，非装饰眉标）与一句图注（11.5px、墨 .78、加 1px 细线 rule，hero 小样 footnote 同款）。
- **响应式**：<960px 塌单栏（工具栏 → 托盘横排或折叠 → 画布 → 侧栏 → 控制条 → 分镜带），四档视口 375/768/1280/1440 无横向滚动。移动端 display 字号二选一并写明：下限抬至 58px（保 5.04 倍），或维持 38px 并在设计说明里标注「clamp 下限档豁免」。

## 4. 画布内容规格（内联 SVG）

- **基座**：横贯画布下缘的墨 .14 圆角色块条（hero 同款 plinth，高约 8px、rx 4），左下标注「运行中的软件 · 运行时」、右下「CORDIS RUNTIME」（11px、字距 .24em、墨 .78）。初始态画布中央只停着这条空基座。
- **积木**：圆角矩形 rx 10、2px 实墨描边、纸白填充；块内左上角小编号（10px、墨 .80），居中标签（Sans 700、15px 实墨；提供者 17px）。五件套与首页 hero 同一词汇：
  - 03 提供者 · 数据库驱动（中央核心，块最高）
  - 04 消费者 · 查询插件、05 消费者 · 聊天插件（各有一条依赖线连向提供者）
  - 01 独立 · 主题皮肤、02 独立 · 日志器（无依赖线，用来演示连锁只沿声明依赖传导）
- **托盘积木件**：同款缩略块竖排六件（提供者 · 数据库驱动 / 提供者 · 备用源 / 消费者 · 查询插件 / 消费者 · 聊天插件 / 独立 · 主题皮肤 / 独立 · 日志器）；「可拖」暗示用虚线轮廓幽灵块或「拖入画布」微字，禁用第二色相高亮。
- **依赖线**：1.6px 贝塞尔曲线 + 箭头 marker，墨 .70（升为正式令牌 `--ink-70`），线上可挂「依赖」微字（hero 同款 scene-note 样式）。
- **状态侧栏**：选中积木检查器（名称 / 类型 / 依赖数 / 运行状态）+ 动作日志（IBM Plex Mono、11px、墨 .82，如「14:02:07 数据库驱动 已移除」「查询插件 连锁熄灭」）+ 一句大白话注解。侧栏属页面 chrome，动效只做面板滑入与状态切换淡切，不与画布抢戏。

## 5. 六拍交互分镜（必须完整，六格一拍不缺）

分镜带六格静态快照为必做交付；同时画布内做同款六拍可播放演示（底部控制条按钮驱动，原生 JS 或 GSAP CDN 均可），两者内容一致。若播放实现与铁律冲突，保分镜带完整并在设计说明里注明。动画只动 `transform` 与 `opacity`，SVG 描线的 `stroke-dashoffset` 是唯一例外；每个场景对外暴露 `play()/pause()/restart()`。

1. **拖入积木**：从托盘拖出提供者与两块消费者，落位带一次过冲回弹（overshoot 回弹）。
2. **连线**：从消费者锚点拖向提供者锚点，贝塞尔依赖线从锚点生长出来（描线动画）。
3. **热替换提供者**：旧提供者「数据库驱动」被抬起抽出基座；熄灭波纹开始沿依赖线逐级传导。
4. **连锁熄灭**：两块消费者依次熄灭——整块降至墨 .14 并微微下沉，依赖线虚化断裂；两块独立积木（主题皮肤 / 日志器）保持点亮：只影响声明过的依赖。熄灭块整块按纯装饰色块处理（块内标签随块变淡，不按文字线判），但同拍必须有持续可读的信息承担者：图注以正文墨 .82 点名哪两块已连锁熄灭。
5. **换源复明**：新提供者「备用源」落位，复明波纹按同样路径反向走一遍，消费者依次复明，依赖线重新画出。
6. **复原**：原样退回去——动作回滚，积木回到托盘、画布回到空基座；「复原」既是按钮也是叙事终点，扣全站主题「让运行中的软件换零件，还能原样退回去」。

**降级要求**：`prefers-reduced-motion: reduce` 时跳过时间轴直出终态、内容不缺失，播放按钮改为「终态与拔除中态」之间淡切。

## 6. 交付自检清单

- 页面可见文本（含 `<title>`、alt、按钮文案）零破折号（`—` 与 `–`，连字符 `-` 除外）；元信息行间隔号 `·` 每行至多 1 个。
- 无 `linear-gradient`、`backdrop-filter`、`blur()`；无纯黑 `#000000`（近黑浓度由实墨承担）；无 `h-screen`。
- 无滚动提示语（Scroll to explore / ↓ scroll / 滚轮动画 / 节号滚动提示）；无装饰性状态圆点（圆点仅在承载真实语义状态时允许，每节至多一个）；无三等分营销卡阵列（分镜带是叙事序列，格与格之间有编号、图注与时间轴语境，不属此列，但不得做成无语境的等宽卡片墙）。
- 非用户触发的编排动效全页只允许一个时刻（画布六拍演示）；托盘与面板入场不做统一 fade-and-slide-up。
- `:focus-visible` 2px 实墨外框（offset 3px）。
- 末尾附设计说明一段：配色、字体、构图、动效分镜各一两句。
