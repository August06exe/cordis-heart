# DesignRead v2 · 视觉重排版（覆盖 v1 的视觉条款）

2026-10-02 · 本文档是 M4.5 视觉重排的唯一视觉基准，与 02-技术方案的工程红线并行生效。
v1 的文案原则（三句话开门、现象先行、可靠度撤出正文）继续有效；v1 的视觉条款（VISUAL_DENSITY 3、留白 25~50%、透明度阶梯用于标题）**全部作废**，由本文取代。

## 0. 失败审计（为什么重排）

用户实测反馈四宗罪，截图证据在案（1440px 整页截图 ×3）：

1. 首页整页高约 9000px，非空白内容不足 10%——「留白 25~50%」被字面化执行成空白成瘾。
2. 序章大标题以 12% 墨渲染成「幽灵字」，不可读。
3. 正文 .78/.82 墨 + 小字号，阅读负担大。
4. 视觉稿承诺的术语卡、图版没有落地，页面无卡片、少图形；钉住场景（首页五拍）无任何进度引导，静止时近乎白纸。

根因：v1 三旋钮 VISUAL_DENSITY 3 + 留白条款 + 「禁三等分卡阵」被九个实现 agent 各自字面化放大。本文用数字封死解释空间。

## 2. 排版阶梯（全局替换，实现进 global.css）

| 元素 | 规格 |
| --- | --- |
| 正文 | 17.5px / 行高 1.9 / sans / **100% 实墨** |
| 小字与图注 | 14px / 墨 .78（全站唯一允许降档的文字，须实测 ≥4.5:1） |
| h1 | 44~52px / serif 900 / 实墨 |
| h2（节标题） | 28px / serif 900 / 实墨 |
| h3（卡题、小节） | 20px / serif 900 / 实墨 |
| 大数字 | 48~56px / serif 900 |
| 幽灵字 | **全站禁用**：任何 ≥24px 的文字，墨度不得低于 40% |

层次靠字号与字重，不靠透明度。透明度阶梯（.14/.20）只用于色块、基座、分隔线。

## 3. 间距与填充率（数字即验收线）

- 节间距：section 上下各 ≤72px；卡片间距 20~24px；段落后 18px。
- 任意 900px 高的视口截图，非空白内容（文字、卡片、图形）占宽 ≥60%。
- 连续纵向空白不得超过 240px。
- 页面总高目标：内容页 ≤4500px，首页 ≤6000px（含 pin 区）。

## 4. 卡片原语（回归为核心版式单元）

`.card` = 2px 墨线边框 + 纸底 + 偏移实影（8px 8px 0 墨 .14）+ 20~24px 内边距。

用于：14 张术语卡（2 列栅格）、统计数字卡、首页路线卡、带走物框、演示卡、边界清单条目。
继续禁止的只有：等宽三列同构阵列、纯白叠纯白的空卡。卡片内部必须有色块、数字或图形承载视觉。

## 5. 动效引导（钉住场景必配，缺即返工）

1. **拍数指示器**：pin 场景右侧固定竖排圆点（实心=当前拍）+ 当前拍名（如「03 · 连锁熄灭」），随 scrub 进度点亮。
2. **场景进度线**：pin 区顶端 2px 墨线，长度随 scrub 进度增长。
3. **默认帧可见**：场景静止初始帧必须是完整「装好」画面（五积木全亮立在基座上），禁止空白或半透明开场。
4. **焦点跟随**：当前拍的主体元素 scale 1.06 + 实墨，非当前拍元素降为 .3 墨——视觉焦点跟着滚轮走。

## 6. 首页章节地图（新增节）

hero 之后新增「九页地图」节：2 列 × 9 张路线卡（页名 + 一句话 + 箭头，卡片原语），直链各页。解决「用户不知道有九页」的问题。

## 7. 图像

每页至少 1 个视觉元素（SVG 图解优先，矢量免费且最贴风格）；已有 11 张插图按清单落位；词典页的视觉由卡片阵列本身承担，不强制插图。

## 8. 保持项（不随重排变动）

单墨钴蓝 #2148B8 / 纸白 #FAFAF7；文案以 src/content/pages/ 文稿为准、一字不改；工程红线六条（只动 transform/opacity、gsap.matchMedia 降级、无 scroll 监听等）；四档响应式无横向滚动；深色令牌按 11-深色令牌定案。

## 9. 截图评审门（每页验收标准）

每页交付两张截图：1440 宽整页、375 宽整页。评审 checklist：

1. 任意 900px 视口内容占宽 ≥60%，连续空白 ≤240px；
2. 正文字号 ≥17px 且实墨（计算样式验证）；
3. 标题 serif 实墨，无幽灵字；
4. 本页承诺的卡片真实存在（glossary 14 卡、index 9 卡地图等）；
5. 钉住场景有拍数指示器 + 默认帧可见（仅首页、沙盒）；
6. 四档视口无横向滚动；
7. 文案与文稿逐段一致；
8. 工程红线 grep 零命中（——、渐变、scroll 监听、纯黑）。
