## 1. 三旋钮终值


维持理由，逐项给新证据：

- **DESIGN_VARIANCE 7**：草稿的推理（编辑风要 5-6、落地默认要 7-9，取 Offset 档顶部）之外，hero 小样把 7 档的两个动作在真实版面上验证了：`cordis-hero.html:77` 的 `grid-template-columns: 40fr 60fr` 非对称分栏成立，`cordis-hero.html:190-203` 验证了 <960px 塌单栏不破版。版面冒险的上限就是这里，不升 8。

## 2. 九页动效强度分层表

分层规则四条，先于一切页面 brief：

1. 强度 8 只属于 `/` 与 `/sandbox`，执行的是 PRD 第 4 节第 1 条分层纪律。
2. 4 与 5 的分界看「核心内容是否藏进操作之后」：不操作就看不到核心内容的页（词典浮层、演示卡）取 5；内容载入即全量在页、用户操作只做点选反馈与既有内容增补的页（借鉴清单生成器）取 4；纯阅读页取 4。全部落在测活待办 e 指认的 4-5 带内。
3. 8 档页允许钉住与滚动擦洗；4-5 档页禁钉住禁擦洗，动效只来自进视口一次性显影和用户交互。例外一处：`/ideas` 的万物过前台按 `05-演示取舍.md` 定为循环动画级（05 的深度口径：定稿的循环动画，能看、能重播，没有输入通路），是全站唯一的有界环境循环，成立条件：不与滚动耦合、滚出视口即暂停、`prefers-reduced-motion` 时定格首帧、保留重播入口。除此之外 4-5 档页维持本条。所有页面遵守 02 第 6 节红线与 `play()/pause()/restart()` 暴露要求。
4. 每页一个 focal event、一个 release zone、至多一处 disruption（mono 配方），动效预算跟着 focal event 走，release zone 不放任何动画。

### 通用视觉词汇（九页共用，出稿 brief 直接引用本节）

以下 token 全部来自已验证的 `cordis-hero.html` 与 brand-spec，出稿时原样继承：

- 开本：页面四缘一圈 1px 墨线框（墨 .20），页边距桌面 22px、移动 14px；报头（wordmark 左、folio 右）、正文、页脚三段以 1px 分隔线切开（`cordis-hero.html:35-52`）。folio 放章节名（如「词典 · 术语卡」），设计小样里的「№ 01」式自编号不搬上正式页。
- 色彩令牌：`--bg` / `--fg`（钴蓝，全页唯一墨）/ `--ink-14` / `--ink-20` / `--ink-78` / `--ink-82`，oklch 取值见 `cordis-hero.html:15-18`；brand-spec.md:10-17 是同一组值的另一套命名（.78 叫 `--muted`、.20 叫 `--border`），出稿令牌名以 hero 小样为准，按 brand-spec 的名字去找取值会扑空。图解线档墨 .70 在 hero 小样里没有独立令牌（`.dep-curve` / `.dep-arrow` 行内 `opacity:.7`，`cordis-hero.html:157-163`），出稿时升为正式令牌 `--ink-70`，取值同式。面板一律 2px 墨线勾勒，不做填充色区分。
- 字体：标题 Noto Serif SC 900，正文 Noto Sans SC 400/500/700，数据场景预留 IBM Plex Mono（brand-spec）。字号跳变线按 mono 技能原文口径执行：最大字为最小字（microcopy）的 5-12 倍（SKILL.md:229，返工线 :344），即 display 对本页最小功能字（图注 11.5px、kicker 12px 一档）≥5 倍，hero 词汇 58/11.5 = 5.04 过线；display 对正文 16px 是 3.63 倍，mono 从未要求这一对到 5 倍，评审不要拿正文当分母打回。已知边界：clamp(38px, 3.6vw, 58px) 在 <1055px 视口落到 38px 下限，对 11.5px 只有 3.3 倍；移动端出稿二选一：display 下限抬到 58px（58/11.5 = 5.04 全程过线），或维持 38px 并在评审记录标注「clamp 下限档豁免」，走了哪条要写明。
- 版面：kicker 12px、字距 .42em、墨 .78，每三节最多一个；大标题 clamp(38px, 3.6vw, 58px)；正文 16px/2.0 墨 .82，列宽上限 26em；图注 11.5px 加 1px 细线（`cordis-hero.html:87-127`）。
- SVG 场景：2px 描边、纸白填充、rx 10 圆角积木立于墨 .14 基座条上，依赖关系用 1.6px 贝塞尔曲线加箭头（墨 .70）（`cordis-hero.html:139-164, 291`）。圆角尺度豁免（定稿补记，field-notes 评审留痕）：rx 10 以 hero 级大积木为基准，hero 五块高 78-148px，rx 占块高约 7%-13%；小尺度构件按块高就近取角，套 rx 10 会近胶囊形，判豁免不判违例。已按此豁免落地的取值：`field-notes.html` 桌面时间线刻度块 44×22 取 rx 5（占块高 22.7%）、纵向时间线刻度 22×14 取圆角 4px（占块高 28.6%）、8px 高基座条 rx 4 与 hero 小样基座（`cordis-hero.html:291`，同为 rx 4）一致；词汇 rx 10 仍约束大积木。
- 无障碍：`:focus-visible` 2px 墨色外框（`cordis-hero.html:187`）；满高用 `min-height:100dvh`，禁固定 `h-screen`；导航单行高 ≤80px；同一页布局族不重样；图标只用 Phosphor / HugeIcons / Radix / Tabler 之一，手绘路径仅限叙事场景 SVG（草稿补充 4，出处 taste-skill 3.C/3.E/4.7）。
- 全站件：可靠度徽标按小节挂（PRD 4.2、6.3），三级（论文原文核实 / 合理解读 / 转引未核实）建议用墨的密度区分（实印 / 网屏 / 细线的印刷隐喻），不引入第二色相，本档建议；每页结尾预留带走物块，形态按 PRD 4.3 三选一，内容由 M3 定。
- 留白：空纸 25%-50%，主对象 45%-80% 且四周露纸，对齐左缘或 2-3 列编辑网格，全部元素居中是失败形态（mono 配方，SKILL.md:145）。
- 插图位图走 gpt-image-2.5-ext @ 2k，prompt 按 mono 配方五段写，与整站同墨（PRD 10）；插图清单 M2 另出，不在本档。

### 每页 brief（出稿骨架）

**`/` 首页 · 强度 8（全力炫位一）**

动效叙事：读者落进首屏，看到 40/60 分栏右侧的五块积木立于基座（hero 小样的静态终态即首屏构图）。往下滚，叙事分五拍推进（滚动区间映射沿用 02 第 4 节表）：0-20% 五块积木从基座下依次浮入落位，两条贝塞尔依赖线用描边动画逐一画出；20-45% 文案切到「拔掉它」，中央「数据库驱动」被抬起抽出基座；45-70% 两块依赖积木依次熄灭（降到墨 .14 并微微下沉；.14 是第 2 节令牌阶梯的底档，02 第 4 节写的 12% 出自旧阶梯 100/60/30/12，不沿用），依赖线虚化断裂，两块独立积木保持点亮；70-95% 提供者归位，熄灭积木依次复明，依赖线重新画出；95-100% 标题落定，场景角出现重播按钮。实现参数：主时间轴 `scrub: 0.5` 配 pin，重播调用 `tl.restart()`；`prefers-reduced-motion` 时跳过钉住擦洗直出终态，重播按钮改「终态与拔除中态」淡切（02 第 4 节已按待办 c 回改口径）。熄灭态文字裁定：块内标签正常态是实印墨（7.48:1），随块降到 .14 后对纸白只剩 1.25:1，熄灭拍整块按纯装饰色块处理，规则 2 的文字线不套用在熄灭标签上；前提是同拍有持续可读的信息承担者：图注以正文墨（.82，8-bit 4.97:1）点名哪两块已连锁熄灭，复明拍随之改写。出稿不得让任何按正文线要求的文字停留在熄灭态。

布局要点：桌面左 40% 文案、右 60% 场景；hero 文本元素至多四个（kicker、标题、副文、图注），顶部留白不超过 `pt-24`；文案用已定稿 A 组（PRD 第 10 节：主「让运行中的软件换零件，还能原样退回去」，副「Cordis 是 deepseek-harness 背后的支撑框架，这个站把它的思想拆给你看。」）；不出现任何滚动提示语；移动端上下堆叠、场景等比缩放（02 第 4 节）。

**`/sandbox` 组件沙盒 · 强度 8（全力炫位二）**

动效叙事：这是九页里唯一「滚动少、手上多」的页面。进入后满高工作台，画布中央停着空基座。用户从积木架拖出「提供者」「消费者」，积木落位带一次过冲回弹；从一个锚点拖向另一个，贝塞尔依赖线从锚点生长出来。热替换提供者时，旧块熄灭，连锁沿依赖线逐级传导（熄灭波纹），换上新源后复明波纹按同样路径反向走一遍，最后一切可「原样退回去」。页面 chrome 的动效只做面板滑入与状态切换淡切，不与画布抢戏。范围声明：设计稿出外壳与画布的视觉语言；状态机建模、积木种类、连锁规则属 M5.5 单独评审（PRD 6.1、草稿第 5 节范围裁定），本 brief 不预设其细节；URL 分享布局是待定项（PRD 第 14 节第 1 条），设计稿预留分享态视觉但不做实现承诺。

布局要点：满高工作台（`min-h 100dvh`）：顶部工具栏 ≤80px 单行，中央画布，右缘或底部检查器面板；面板 2px 墨线勾勒不填充；Ctrl+Z 在本页优先交给沙盒撤销栈（PRD 第 8 节）。版式上它不是开本阅读页，但墨、线宽、圆角体系与九页完全同源。深链自 `/ideas`（PRD 第 5 节）。

**`/ideas` 五个核心思想 · 强度 5**

动效叙事：滚动只推进章节，节与节之间轻交叉淡；每个思想节里动效的主菜是演示卡。演示取舍以 `05-演示取舍.md`（M2 决断稿）为准，本页不再沿用 02 第 5 节四个全做的旧口径：撤销堆栈（完整交互级）与生命周期状态机（完整交互级）由用户触发，载入时停在第 0 帧并显示「播放」，点击后 GSAP 时间轴运行，可暂停可重播；前者按 LIFO 弹栈回放逆动作，后者重点做「停用中」那一拍的等待感。万物过前台定案为循环动画级（05 深度口径：能看、能重播、没有输入通路），小方块沿 MotionPath 流经同一柜台、柜台账本逐笔记账，进视口循环播放、滚出即停，成立条件见第 2 节分层规则 3 的例外条款。搬箱子不做：它的「不同顺序搬运、终点货架一致」顺序无关论点在素材里立不住（定理 5 讲逐步记账等于一次记完，定理 11 讲组合仍可撤销，都推不出终点态与顺序无关，`05-演示取舍.md:47`；本档作者已通读 `20-content/素材/02-两大核心机制.md` 全文证实），交换与组合小节改静态对比图加一句注解、徽标挂「合理解读」（`05-演示取舍.md:51`），不占演示卡槽位。滚动永不驱动演示。

布局要点：每思想一节，节内布局在 40/60 分栏与上下堆叠之间轮换，同一页布局族不重样；为每个演示预留「演示卡」槽位：场景区、一句大白话注解、播放/暂停/重播控制条；演示落位按 05 的五小节覆盖表执行（`05-演示取舍.md:79`：可逆效应→撤销堆栈；响应式反效应→生命周期状态机；统一通道→万物过前台；交换与组合→静态图；组件沙盒→王牌深链），静态图走插图管线、不占演示卡槽位；沙盒王牌放深链入口卡（PRD 第 5 节）。带走物槽位落在本页（知识卡形态属 M6 彩蛋，先留位）。

**`/glossary` 词典 · 强度 5**

动效叙事：术语卡网格随滚动轻入场（每卡 stagger 约 60ms、位移 ≤12px 的一次性上浮）。hover 或键盘 focus 时浮层淡入并轻上浮 8px，定位交给 @floating-ui/dom（02 第 1 节选型），浮层里三段内容依次显影：大白话定义、生活类比、论文出处（PRD 第 5 节）。除此之外页面安静，让「查」这个动作快进快出。

布局要点：ruled information poster 或 archival plate 版式（mono 配方 compositions.json:7,8 的索引页映射）：细线信息带加题注；卡片网格禁止三等分营销卡阵列，按内容长度自然分栏或两列锯齿；术语与编号用 Programmatic 声部（黑体/mono 锚点，mono 配方 typography.json:34）；display 对本页最小功能字的字号跳变 ≥5 倍（口径见第 2 节字体条，mono SKILL.md:229）。关键段落自含、可整段复制（PRD 第 2 节喂 AI 场景）。

**`/why` 序章·为什么 · 强度 4**

动效叙事：进页用 View Transitions 接住，往下滚，每一节进视口时统计数字做一次 count-up 显影（lieflat 实测选型的 G18 Draw-in + Counter 同款），「重启的代价」「VSCode 87/100」这类数字落定后静止；「重启的代价」节可配一张单墨示意图的 DrawSVG 描线，画一次就停。没有钉住，没有擦洗。

布局要点：editorial journal 版式族（mono 配方 compositions.json:12 的阅读页映射）：主图加强标题加有纪律的正文栏；数字全部出自素材 01，逐条挂可靠度徽标；数字禁虚构（第 3 节禁令 8 的重点页）。

**`/field-notes` 实录 · 强度 4**

动效叙事：Koishi 生态图表进视口时 Draw-in 加计数器显影一次，随后完全静止供阅读；dsh 勘察要点列表按 stagger 轻入场。图表本体是 lieflat-charts 导出的独立 SVG/HTML（PRD 第 10 节），动效发生在图表自带层，页面不给它叠加滚动效果。

**`/steal-this` 借鉴清单 · 强度 4**

## 4. 每页视觉稿的评审标准（scorecard）

每页视觉稿六条全过才收，任何一条 FAIL 打回重出。每条写明阈值与验证方法；本轮已实跑的项标注结果，未实跑的标注状态。

**规则 1：单一色相（node 全文件扫描）。**
方法：对交付 HTML 全文提取 hex 与 oklch 色值，换算 OKLCH 色相；色度 C ≥ 0.02 的色值必须同属一个色相（钴蓝 265，容差 ±5°），C < 0.02 视为中性基底豁免（纸白 C=0.004 即走此门）。命令即本轮实跑脚本（见文末附录），对每页重跑一遍。本轮对 `cordis-hero.html` 实跑结果：色相集合 {265}，两处中性基底豁免，PASS。深色页口径（修订轮定）：色相锚不取绝对 265°，取该页深色基墨本体的实测色相（当前 08 样张 `#a0b4ee` = 269.6），全文件 C ≥ 0.02 色值按基墨 ±5° 判。理由：深色基墨是同色相提亮的推导值，色相相对 catalog 钴蓝已漂 4.6°，绝对锚会把推导链本身判死；单色相规则的本意是「一页一墨」，锚随墨走才是忠实执行，浅色页维持绝对锚（钴蓝是 catalog 原值，无漂移问题）。修订轮已对 08 样张全文补跑（13 个不同 hex，20 处出现；node，CSS Color 4 矩阵，见附录 5）：按绝对锚，样张注释里两处合成值越线——`#262B3A` H=270.3（C=0.028）、`#8494C4` H=270.1（C=0.074），上限 270.0 被吃满；按基墨锚全文件 PASS，最远 270.3 距锚 0.7°；`#12151D` / `#10131B` / `#161A23` C<0.02 中性豁免。

**规则 2：文字对比度 ≥4.5，表意图形线 ≥3（node 实算 WCAG）。**
方法：alpha 令牌先在 sRGB 上对底色合成，再按 WCAG 相对亮度公式算对比度。文字（含图内编号文字）≥4.5:1；承载信息的图形元素（依赖线、箭头、图表线）≥3:1；纯装饰（基座 .14、分隔细线 .20）豁免 3:1 义务。阈值出处：WCAG 1.4.3 与 1.4.11，02 待办 a 的 60% 档裁定。**口径裁定（修订轮起执行）**：alpha 合成有浮点直算与 8-bit 取整两种口径，差 0.01-0.02；8-bit 与浏览器实际渲染一致，一律以 8-bit 为判定口径，浮点值仅作文档对照。此前两层口径是混用的：浅色侧既有文档值（02-配方、brand-spec 及本表 v1.0 版）是浮点直算，深色侧 08-审记是 8-bit；08 样张头注释 @.82=4.17 是浮点，08-审记同格 4.18 是 8-bit。对比度落在红线 0.05 以内的档必须双口径都过线才算 PASS。修订轮复算（node v22.23.2）：浅色侧浮点 3.764 / 4.520 / 4.735 / 4.960（.70/.78/.80/.82，与既有文档值分毫吻合，证实其为浮点口径），8-bit 为 3.778 / 4.524 / 4.716 / 4.966，判定全部不变；深色侧 8 组（8.91 / 6.32 / 6.10 / 5.86 / 4.93 / 1.49 / 1.29 / 6.89）按 8-bit 与 08-审记逐组一致；`#6b8be6` 阶梯浮点 @.82=4.17、8-bit @.82=4.18，证实两文档各用一种口径。下表判定值已换为 8-bit，浮点值括注：
