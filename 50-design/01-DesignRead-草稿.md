## 5. 范围裁定（技能 13）

技能的自我排除清单里有「多步产品 UI / 仪表盘」。组件沙盒（PRD 6.1）本质是迷你互动工具，跨进了这条排除线。裁定：技能管辖沙盒的外壳（单墨视觉语言、圆角体系、排版、性能与无障碍红线），沙盒内部的状态机与交互建模不在本技能管辖内，以 02 6 工程红线与 M5.5 规格评审为准。词典卡与抄作业生成器是内容组件，仍归编辑风全权管辖。首页、序章、五思想、实录、借鉴、边界、存疑七页完全在管辖内。

### 6.3 有理由的例外：两处，均合规

1. 思源宋体做标题。技能 4.1 对衬线默认强烈劝退，但豁免分支「美学家族确实是编辑 / 出版 / 印刷」在本简报成立：单墨印刷语言是明写的定调。属有理由的例外，不是漂移。技能点名的两款被禁衬线（Fraunces、Instrument Serif）不在使用范围。思源宋 / 黑是中文场景的合理选型，技能推荐的拉丁字体（Geist 等）不适用于中文正文。
2. 内联 SVG 几何场景。技能 4.8 对手绘装饰 SVG 强烈劝退，豁免条件「简报明确要求」成立：02 4 明写场景为内联 SVG 几何形体，且 02 6 禁视频红线决定了叙事场景必须矢量化。插图（位图）则按技能 4.8 的优先级走画图 MCP 生成，插图清单随 M2 定。

### 6.4 冲突与待办：一处规则级冲突，四项补充

**冲突 1（唯一实质发现）：透明度阶梯 60% 档不达 AA。** 实测钴蓝 60% 透明度混入纸白后对比度 3.02:1，低于 AA 正文线 4.5:1，仅够大字号 AA 线（3:1）。02 2 把 60% 档定为「次要信息」用色，若该档用于正文级小字，违反技能 4.5 与 14 节的强制对比检查。裁定：60% 档限大字号（18px 加粗以上或 24px 以上）与装饰用途；正文级次要信息用 100% 墨；30% 与 12% 档只做熄灭态与装饰，不承载文字，无 AA 义务。按 PRD 10 约定应回改 02，本文档只记录裁定，回改动作留给项目主流程。

补充 2：`MOTION_INTENSITY 8` 作为全局基调成立，但页级分层（全力炫两页 8、编辑章节 4-5）是技能「动效必须有动机」规则下的必做项，不是可选项。与 02 9.5 预留一致，M2 分层清单定稿即闭环。

补充 3：深色主题（暗纸底）的对比度本次无法验证，深底样张 M2 才出。技能 6.C 要求双模式都过 AA，钴蓝在深底上的表现是样张的验收项之一，标记待验证。

补充 4：技能的若干实现级硬规则 02 未提及，出视觉稿与写码时须带上，属补充不属漂移：满高用 `min-h-[100dvh]` 禁 `h-screen`（3.E）；眉标（uppercase 小标签）每三节最多一个（4.7）；Hero 顶部留白上限 `pt-24`，Hero 文本元素至多四个（4.7）；导航单行且高度上限 80px（4.7）；同一页布局族不重样（4.7）；图标只用 Phosphor / HugeIcons / Radix / Tabler 之一，禁手绘图标路径（3.C，注意与「场景 SVG」的豁免区分开，那条豁免只覆盖叙事场景与几何插图）。

补充 5：技能 12 节的 Block Library 在本安装中只有 schema 没有 block 文件（技能目录下仅 SKILL.md），其正文也自述「iteratively」。设计读数阶段不受影响；进入实现阶段时没有现成 block 可抄，按 5.A / 5.B / 5.C 的代码骨架自行落地。
