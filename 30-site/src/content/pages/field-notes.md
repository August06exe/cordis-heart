# 一颗跑了七年的心脏

先说数字，再说故事。

2026 年 10 月 1 日，我们沿 GitHub API 把 dsh 摸了一遍：star 241,568，创建仅七周，最近五条提交全部落在同一天，PR 编号排到四位数。它不是热点过后的空壳，是正在高速运转的活项目。

但 dsh 是 8 月才出生的。「一切皆插件」的功夫，不可能七周练成。功夫在哪？在 Cordis 身上。

## 故事的起点，是一个 QQ 机器人

2019 年底，开发者 Shigma（石逸凡）开源了 Koishi——一个跨平台聊天机器人框架。它从第一天起就要面对最凶险的问题：**几千个互不相识的人写的插件，塞在同一个进程里，随时装上、卸下、互相调用，怎么才能不把彼此弄死？**

这问题听着像行业难题，其实每个人都懂：你给编辑器装了个插件，用腻了想卸载，它说「请重启」。你只是想拿走一个零件，它却把整栋楼断电重开。

2022 年，Shigma 把 Koishi 里最硬的那块内核拆出来单独开源，取名 **Cordis**——拉丁语的「心脏」。此后四年，这颗心脏在 Koishi 身上养出了一个 4000 多个插件的生态【转引：论文口径，本站未独立核实】。

## 心脏的图纸，写成了论文

2026 年，石逸凡（北京大学 & DeepSeek-AI）与合作者把这套跑了七年的东西写成 88 页的论文，就是本站拆解的《时空可组装性的一种编程范式》。同月，DeepSeek 把 Cordis 整个装进 dsh，当 Agent 框架的地基。

四者的分工一句话说完：**论文立论，Cordis 把论点做成框架，Koishi 是它跑了多年的先例，dsh 拿它做 agent 时代的地基。**

- **4,000+** — Koishi 社区插件（论文口径，本站未独立核实）
- **7 年** — Cordis 思想在生产环境连续服役（2019 至今）
- **241,568** — dsh 的 star（2026-10-01 勘察值）

诚实声明：论文第 70 页自己交代，证据是观察性的（有生态、无对照实验），性能开销未量化。我们把这些一并摆上桌，不藏着。
