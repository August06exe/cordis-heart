# DeepSeek 又出手了，这次不是大模型

8 月 13 日，DeepSeek 悄悄开源了个新东西。（对，就是那个 DeepSeek。）

没开发布会，没晒跑分，就丢出一个叫 **deepseek-harness**（大家叫它 dsh）的框架，招牌一句话：「一切皆插件。」

然后 GitHub 趋势榜没了悬念：首日 star 以万计【转引：媒体报道有出入，取「数以万计」口径】，几天破 15 万，七周 24 万【转引：dsh 仓库 API 实测 241,568 star，2026-10-01 快照】，媒体管它叫「史上最快涨星项目」——作为对比，OpenAI 的 Codex CLI 爬到 10 万用了好几年。那阵子，你的群里多半有人晒过它。

热闹看完了，说点热闹背后的。dsh 肚子里装着几千个互不相识的人写的插件，随时装上、卸下、互相调用，居然一直没散架。懂行的看到这儿会愣一下：这事，凭什么？

答案写在 README 的第一行：**Powered by Cordis。**

> 一个装着几千个插件的程序，  
> 插件随时装上、卸下、互相调用，  
> 凭什么不散架？

答案藏在 README 的第一行：**Powered by Cordis。**

Cordis 是一个 2022 年就开源的老框架，它背后还有一篇 88 页的论文：《时空可组装性的一种编程范式》。「时空可组装性」这七个字翻译成人话就是：**软件在运行中换零件，时间和空间上都要靠得住**：装上立刻生效，卸掉不留痕迹，谁依赖谁都算数。

dsh 的「一切皆插件」敢不是口号，正因为 Cordis 把这七个字做成了机制。这个站，就是把那篇论文和这套机制，拆成不懂技术的人也能读懂、能直接用的一本小书。

**这本小书的路线，跟着 DeepSeek 的脚印走：**

- **第 1 站 · 由来** — dsh 有多火、Cordis 从哪来：一个 QQ 机器人内核，怎么长成 24 万 star 项目的地基。
- **第 2 站 · 一页纸总结** — 88 页论文，压成一页：它解决什么问题、两句核心、四条保证。
- **第 3 站 · 词典与拆解** — 14 张术语卡 + 五个核心思想，每个思想配一个你能懂的例子。
- **第 4 站 · 动手与照抄** — 亲手拔积木的沙盒、十五条可以勾选的打法、每页一段复制给 AI 的话。
